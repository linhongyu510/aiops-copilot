# Linux Load Average 过高处理方案

## 识别信号

Load Average 明显超过 CPU 核数，但它同时包含可运行和不可中断睡眠任务，不能直接等同于 CPU 使用率。

## 排查顺序

1. 对比 load、CPU user/system/iowait 和运行队列。
2. 查看高 CPU 进程、D 状态进程和线程数。
3. 检查磁盘、网络存储、内存回收和 swap。
4. 对齐定时任务、发布、备份或流量峰值。
5. 区分短暂尖峰与持续饱和。

## 止损与恢复

暂停确认无关的批任务、限流或迁移流量。禁止仅凭 load 数值杀进程。恢复后运行队列、iowait 和业务延迟应同步回落。

## 升级条件

大量 D 状态无法退出、内核告警或共享存储异常时升级系统与存储团队。
