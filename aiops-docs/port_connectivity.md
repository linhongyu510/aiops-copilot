# TCP 端口连通性故障处理方案

## 识别信号

连接表现为 refused、timeout 或 reset。三者分别更可能指向无监听/主动拒绝、路径丢包/防火墙、连接被中途终止。

## 排查顺序

1. 确认目标域名、解析 IP、端口和协议。
2. 在目标主机确认监听地址及进程。
3. 从与调用方相同网络位置进行受控连接测试。
4. 检查安全组、防火墙、NetworkPolicy、负载均衡健康。
5. 对齐连接失败时间与发布、网络策略变更。

## 止损与恢复

使用已验证的备用端点或回滚错误网络策略。不要通过临时开放全网访问解决单端口问题。恢复后从真实调用路径验证握手与应用协议。

## 升级条件

跨可用区同时失败、路由不对称或负载均衡控制面异常时升级网络团队。
