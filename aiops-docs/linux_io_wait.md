# Linux IO Wait 过高处理方案

## 识别信号

CPU iowait、磁盘 await 或队列深度升高，业务延迟与 IO 指标同步。需定位具体设备和读写来源。

## 排查顺序

1. 查看各块设备吞吐、IOPS、await、util 和队列深度。
2. 定位高读写进程及文件路径。
3. 检查文件系统空间、inode、错误和内核日志。
4. 对齐数据库 checkpoint、日志轮转、备份或 compaction。
5. 云盘场景核对性能额度和突发余额。

## 止损与恢复

暂停非关键批量 IO、降低写入并发或切换副本。不要在高 IO 时执行大规模压缩清理。恢复后 await、队列和业务 P95 应共同下降。

## 升级条件

设备错误、只读挂载、延迟持续恶化或涉及数据完整性时升级存储负责人。
