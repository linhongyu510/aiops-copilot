# 应用内存泄漏处理方案

## 识别信号

在负载稳定且 GC 后，内存基线仍随时间单调上升；重启后暂时恢复但趋势重复。

## 排查顺序

1. 区分堆、堆外、原生内存、页缓存和容器 working set。
2. 比较 GC 后存活对象或不同时间点内存快照。
3. 检查无界缓存、监听器、线程本地变量、连接与缓冲区。
4. 对齐版本、流量类型和定时任务。
5. 估算达到 limit 的剩余时间。

## 止损与恢复

滚动重启、限流或关闭泄漏功能仅作为止损，并保留至少一个实例证据。修复后进行长稳测试并比较内存斜率。

## 升级条件

增长速度会在短期触发 OOM、转储含敏感数据或泄漏位于第三方运行库时升级负责人。
